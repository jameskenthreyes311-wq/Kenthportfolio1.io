# KENTH.SYS — Memory Protocol

A futuristic memory card game themed after **Kenth James P. Reyes'** portfolio.

## Design System
Matches the portfolio exactly:
- **Fonts**: Syne (headings/UI) + Outfit (body/mono)
- **Colors**: `#0C1E22` base, `#2D4A52` / `#586C77` tones, `#00d4ff` cyan accent
- **Style**: Animated grid background, CRT scanlines, custom cursor, terminal UI, corner brackets, glow effects

## Files
```
kenth-memory-game/
├── index.html   ← Game markup
├── style.css    ← Futuristic styles
├── script.js    ← Game logic
└── README.md
```

## How to Run
Open `index.html` in any modern browser. No server or build tools needed.
